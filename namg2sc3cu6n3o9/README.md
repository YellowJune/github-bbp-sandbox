# NaMg2Sc3Cu6N3O9 validation

Generated H-free low-pressure candidate from the charge-compensated oxynitride search.

Constraints:
- no hydrogen
- 0 and 400 atm structural relaxation
- compare three distinct Na/Mg/Sc/N orderings
- NaMg5Cu6O12 all-oxide control

This workflow is only a structural falsification step. CHGNet survival is not evidence of superconductivity. A surviving ordering must next pass DFT(+U)/PDOS, charge-state, and many-body validation.
